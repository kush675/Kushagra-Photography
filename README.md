# Kushagra — Photography

A minimal photography portfolio by Kushagra, a BDes student in Communication Design. The current selection contains 21 photographs across Portrait, Product, Wildlife and Macro collections.

## Website hosting

The public HTML, styles and image viewer are hosted by GitHub Pages. Original photographs, lossless full-resolution detail and the live photo catalog stay in the existing durable photo service at https://kushagra-photographic-studies.aquabow1.chatgpt.site. The viewer and photo quality are preserved. Do not shut down that service or clear its stored files after enabling Pages.

## Publish with GitHub Pages

In this repository, open **Settings → Pages**, choose **Deploy from a branch**, and select **main / (root)**. Save and wait for GitHub to report the deployed address. The expected project address is https://kush675.github.io/kushagra-photography-portfolio/ . An address in this README alone is not proof that publication has completed.

## Owner photo management

Bookmark [admin.html](admin.html) or open https://kushagra-photographic-studies.aquabow1.chatgpt.site/admin. It opens the existing authenticated owner studio, where only the verified owner can upload, edit or delete photographs. Visitors do not receive an upload or management control. No password, secret or authentication key is stored in this public frontend. The live catalog means owner photo updates appear without rebuilding Pages.
